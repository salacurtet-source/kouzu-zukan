# 構図コンプリート図鑑

33種類の構図を撮り集める、写真好きのための撮影記録アプリ（PWA）。

- 構図図鑑：33構図をコンタクトシート風に一覧。写真か記録を登録すると赤いセレクト枠が付く
- お題ガチャ：構図・枚数・縛り・ロケ地をランダムに出して、挑戦と達成を記録
- ロケ地マップ：撮影スポットの座標・ベストな月・時間帯・相性のいい構図を記録
- 虎の巻：F値・シャッタースピード・ISO感度・ホワイトバランスの基本と使用例、体験シミュレーター、メーカー別コラム
- 33構図すべてにイラストの作例付き

写真と記録は端末のブラウザ内（IndexedDB）にだけ保存されます。右上の「端末に保存」からバックアップを書き出せます。

- iPhone：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chromeで開く → メニュー → 「ホーム画面に追加」
